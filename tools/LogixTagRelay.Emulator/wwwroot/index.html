Script helpers
plc.get('Tag.Path') reads a typed value. LINT/ULINT/DT/TIME/LTIME/LDT values are JavaScript BigInts; DT/TIME/TIME32 use microseconds; LTIME/LDT use nanoseconds.
plc.set('Tag.Path', value) stages a PLC-side change. All staged writes commit together.
plc.changed('Tag.Path') detects a change since the last committed tick; it is true on the first tick.
plc.log(message) adds a line below. Keep state between ticks using properties such as state.target.
